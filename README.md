# 中秋海邊烤肉攤

單檔 HTML 小遊戲：中秋夜的海邊烤肉攤，照客人的點單把食材依序串好、烤到「完美」再端出去。一局 90 秒。

## 怎麼玩
1. 客人從右側走進來排隊，頭上氣泡是他要的食材（**順序要一模一樣**）。
2. 點下方食材依序串到組裝區（最多 4 個），放到烤架空格。
3. 看熟度條：太生 → 有點沒熟 → 熟了 → **完美** → 焦了。烤到完美得分最高，焦了會倒扣。
4. 點烤好的串把它拿起來（也可以按住拖曳），再點客人交餐；烤焦或串錯的拿起來丟進垃圾桶。
5. 送錯餐不會被收走，但客人會更不耐煩；客人等不及會氣走並扣分。

## 操作
| | 滑鼠 / 觸控 | 鍵盤 |
|---|---|---|
| 串食材 | 點食材 | `1`~`6` |
| 復原上一個 | 點 ↩ | `Backspace` |
| 放上烤架 | 點烤架空格或「放上烤架」 | `Space`（放到第一個空格）或 `Q W E / A S D`（指定格） |
| 拿起烤串 | 點烤串（或按住拖曳） | `Q W E / A S D` |
| 交餐 | 點客人（含頭上氣泡）／拖曳放開 | `Y U I O P`（隊伍由左到右） |
| 丟棄 | 點垃圾桶 | `X` |
| 火力 | 點 − / + | `-` / `=` |
| 暫停 | 點左上 ⏸ | `Esc`（手上有串時先放回去） |
| 音效 / 音樂 / 震動 | 點左下的喇叭、音符、手機圖示（分開開關，會記住；震動只在裝置支援時才會出現，iOS Safari 不支援） | `M` 全部靜音 / 取消靜音 |

手機請直向遊玩（橫放會出現提示）。切到別的視窗會自動暫停。

## 怎麼開
直接用瀏覽器開 `index.html` 即可，不需要伺服器或建置。美術都在 `assets/`。

> 要在 Claude 的預覽窗格或手機上測試，可以用 `.claude/launch.json` 裡的 `bbq-static`（本機小伺服器，`python -m http.server 8765`），因為預覽窗格讀不到相對路徑的圖。

## 專案結構
```
index.html            遊戲本體（Canvas，單檔）
assets/               遊戲用的圖（由 tools/process_assets.py 產生）
assets/raw/           Codex 生成的原圖（綠幕）與封存的舊版
ASSETS.md             美術規格、風格、角色名單、流程
tools/process_assets.py   去背 / 縮圖 / 依頭部對齊裁切
tools/check_raw.py        新圖審查前的客觀檢查（尺寸、純綠背景、貼邊）
```

## 難度曲線
壓力隨時間往上爬（都在 `CFG.phases`，可直接改）：

| 秒數 | 補客人間隔 | 同時在場上限 | 點單長度（食材數）機率 |
|---|---|---|---|
| 0 | 9 秒 | 2 位 | 全是 2 個 |
| 15 | 7 秒 | 3 位 | 2 個 80%、3 個 20% |
| 35 | 5 秒 | 4 位 | 2/3/4 個 = 35%/45%/20% |
| 58 | 3.5 秒 | 5 位 | 2/3/4 個 = 10%/40%/50% |
| 78（**最後衝刺**） | 2.4 秒 | 5 位 | 3/4 個 = 30%/70% |

- 間隔與機率在相鄰兩段之間**平滑漸變**；上限在進入新階段時才放寬。
- 客人的耐心也隨時間縮短（結束時只剩約 58%），出客間隔還有 ±15% 隨機。
- **點單越複雜分數倍率越高**：2 個食材 ×1、3 個 ×1.7、4 個 ×2.6，氣泡右上角會標出倍率。
- 開局刻意放得很緩，給新手熟悉操作；用機器人實測，各種速度的玩家在前 35 秒幾乎不會掉客人。

## 調整數值
全部在 `index.html` 最上面：
- `CFG`：一局秒數、烤熟各階段秒數與分數、客人數量與出現間隔、耐心、小費與連擊、結算稱號門檻。
- `INGREDIENTS`：食材的烤熟速度與解鎖時間。
- `CUSTOMERS[].scale`：每位客人立繪的顯示大小（換新圖後要並排重新校準）。
- 遊戲中也可以用 −/+ 調火力（整體烤熟速度，50%~200%，會記住）。

## 更新美術
> 倉庫裡只有處理好的成品（`assets/`）；Codex 的原圖與被退件的版本（`assets/raw/`，約 36 MB）沒有放進來。要重新處理成品，需要自備原圖。

1. 依 `ASSETS.md` 的風格與規格生成新圖，放進 `assets/raw/`（命名 `ing_<id>.png`、`cust_<id>.png`……）。
2. （可選）`python tools/check_raw.py cust_wolf ing_pork` 先做客觀檢查。
3. `python tools/process_assets.py` 重新去背、縮圖到 `assets/`（需要 Pillow：`pip install pillow`）。它也會自動更新 `index.html` 裡的 `ASSET_VER`，讓瀏覽器重新下載新圖，不會一直顯示快取的舊圖。
4. 新的圖要加進 `index.html` 的 `ART_FILES`。

## 音效
全部用 Web Audio 即時合成，沒有任何音檔（不用授權、不增加檔案大小）：
- 24 種短音效（串食材音高隨數量上升、完美交餐是上行琶音、連擊越高音越高、倒數最後 5 秒滴答……），都在 `index.html` 的 `Sound` 裡。
- 烤架上的串越多，滋滋聲越大；有輕微的海浪聲。
- 背景音樂是五聲音階的隨機旋律，最後 20 秒逐漸加快；暫停時音樂壓低。
- 瀏覽器規定要先有使用者操作才能發聲，所以第一次點擊後才會開始有聲音。

## 手感
- **特效**：交餐的金色火花與光環（連擊越高越華麗）、烤焦冒黑煙、放上烤架冒蒸氣、完美時槽位金框脈動、送錯或烤焦時畫面輕震、新紀錄灑彩帶。
- **動畫**：烤串從上面落下、串食材時最後一個彈跳、客人呼吸與微晃、走進來時上下顛簸、氣泡微浮、分數數字滾動。
- **震動**：和音效同名同時機，各自有開關（`Haptic`）。
- **安全區域**：已處理瀏海與下方手勢條（`env(safe-area-inset-*)`）。
- **保護**：同時發聲的音效最多 32 個、同名音效有最小間隔，狂點按鈕也不會疊到爆音。

## 測試
在專案根目錄開本機伺服器（`python -m http.server 8765`），再開 `http://localhost:8765/tools/test.html`，按「執行全部測試」（網址加 `?auto` 會自動跑，跑完分頁標題會變 `PASS n/n`）。

目前 12 項：素材與設定、音效名稱對照、音效引擎、音效保護、壓力曲線單調、稱號門檻、遊戲流程冒煙、交餐與計分、隨機壓力測試、機器人難度曲線、繪圖冒煙、特效／震動／安全區域。

- **測試是靜音的**：測試頁會把遊戲音訊的主音量設為 0，而且把一整局壓縮在幾十毫秒內跑，所以不會有聲音，也不會震動。
- **測試不會動你的設定**：每個測試前後都比對音效、音樂、震動、火力設定，被動到就判失敗並還原（隨機壓力測試因為會亂點到設定按鈕，是唯一例外，由執行器還原）。
- 改了數值（壓力曲線、稱號門檻、倍率）或加了新功能後，跑一次就知道有沒有改壞。

## FEVER TIME
交出「熟了」「完美」的餐點會充能量條（送錯、客人走掉會扣一點），滿了進入 12 秒狂熱：烤串一放上烤架（或拿在手上）就直接是完美、不會焦；來客間隔縮成 0.3 倍、隊伍開到上限；得分 ×2、客人耐心凍結；背景轉熱紅色、音樂換成更快更高的版本。參數在 `CFG.fever`。
