【專案背景】
D:/!Projects/BBQ 是單一檔案的 HTML Canvas 小遊戲《中秋海邊烤肉攤》（遊戲全部在 index.html，約 1600 行）。
玩法：6 個烤位、從食材盤依序串 3–6 種食材成一串、烤到剛好熟、交給排隊客人；90 秒一局，之後結算。
有手動交付、垃圾桶、火力調整、壓力曲線（客人出現越來越快、點餐越來越複雜）。
桌機（鍵盤＋滑鼠）與手機（觸控，Pointer Events）都要能玩。聲音全部用 Web Audio 即時合成。
遊戲預計用 GitHub Pages 公開給陌生人玩。測試在 tools/test.html（12 個測試）。

【請重點審查】
1. 遊戲邏輯正確性：計分（含複雜度倍率）、熟度階段與時間、客人耐心與離場、排隊生成（同時不得有兩位相同頭像）、局結束與重開是否殘留狀態。
2. 計時與暫停：update(dt) 的 dt 處理、分頁隱藏／自動暫停後回來、暫停時計時器與音效是否會繼續或錯亂。
3. 音效引擎：AudioContext 啟動（瀏覽器需使用者手勢）、同時發聲數量上限、節點是否洩漏（建立後沒有斷開或停止）、靜音／音樂開關是否真的停掉。
4. 輸入：滑鼠與觸控是否會重複觸發、鍵盤快捷鍵（YUIOP/QWEASD/1–6/Space/X/Esc/M/−/=）衝突、快速連點或同時多指的邊界情況。
5. localStorage：讀不到、被禁用、內容壞掉時是否會讓遊戲壞掉。
6. 效能與記憶體：每影格是否有不必要的配置或排序、粒子是否有上限、長時間遊玩是否會累積。
