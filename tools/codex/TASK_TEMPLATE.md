# Codex 任務檔範本（生圖）

存成 `tools/codex/tasks/<任務名>.txt`，用 `tools/codex/run_task.sh <任務名> 參考圖…` 交付。
**每一段都是上次付過代價才加的**；沒有寫到的事，Codex 就會自己決定（或停下來問而空手結束）。

```text
請使用你的圖像生成功能，為「<專案簡介>」生成一張<素材類型>。

【硬性規則】
- 只能新增 <專案絕對路徑，用正斜線>/assets/raw/<檔名>.png 這一個檔案，不要修改或刪除專案內任何其他檔案。
  assets/raw 內其他 png 都是參考或封存的圖，請不要動，也不要拿來當風格參考（除非下面明確附上）。
- PNG，正方形 1024x1024。完成後回報實際路徑、像素尺寸、最終使用的 prompt。
- 生成後請自行檢查：背景是否為純綠 #00FF00、主體有沒有綠色、有沒有文字或多餘物件、是否完整在畫面內；不符合就重生成。

【授權】                                           ← 一定要有，否則非互動模式會停下來問、然後空手結束
生成工具輸出的尺寸或背景常常不完全符合規格。你「可以」用程式（例如 Python + Pillow）把圖縮放／補邊成 1024x1024，
並把近似綠色的背景精確校正為純綠 #00FF00（只改尺寸與背景，保留主體畫風）。這是明確允許的，不需要再詢問我。

【風格】                                           ← 附上已核准的圖（-i），並用文字說明「要和它一致的是什麼」
附上的圖片 <範本檔名> 是已通過審查的範本，請讓這張的「畫風、渲染方式、大小比例」與它一致，
但**不要複製它的臉、髮型、服裝或姿勢**（新角色）。
<風格關鍵字，英文 prompt 效果較穩>

【內容】
<具體描述：主體、顏色（要寫哪一個是「唯一點綴色」）、姿勢（要指定，並禁止交疊雙手等僵硬姿勢）、表情>

【構圖】
<主體占畫面比例；四周／左右留白；頭頂距上緣；身體只可在下緣被截斷；單一主體置中>

【禁止】
不要文字、浮水印、地面投影、道具、其他角色；不要竹籤（食材）；角色本身（衣服、頭髮、眼睛）不得使用綠色。
背景：整張純綠 #00FF00，無漸層、無紋理、無陰影。注意：主體的綠色（若有）必須與背景明顯區分（偏黃、偏深、偏灰）。
```

## 退件重做要加的段落
```text
【退件重做】
附上的第二張圖 <被退的檔名> 是目前的版本，被退件的原因：<一句話原因>。
請保持同一個角色（<列出要保留的識別：臉、髮、服裝、配色、構圖>），**只改：<要改的一件事>**。
```

## 審查清單（Claude 自己做，不要叫 Codex 自評風格）
1. `python tools/check_raw.py <檔名…>`：尺寸、四角純綠、貼邊、亮度。
2. 目視（一次只看通過第一關的；多張時先做聯絡表）：風格是否像範本？縮成圖示還認得出來嗎？姿勢自然嗎？和既有角色會不會混淆？
3. 通過 → `python tools/process_assets.py`；退件 → 改名加後綴封存（`_v3_rejected`…）再重做。
